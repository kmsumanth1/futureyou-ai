# FutureYou AI 🚀

## AI-Powered Career Prediction System

FutureYou AI is a smart and interactive web application created to help students understand their future career opportunities based on their current skills and interests.

Many students are confused about:

* Which career path suits them best
* Which skills they should improve
* Whether they are industry-ready
* What salary range they can expect

FutureYou AI solves this problem by analyzing a student's:

* Skills
* Interests
* Projects
* CGPA
* Technical strengths

Based on this information, the system predicts the most suitable career path and provides useful suggestions for improvement.

The project was designed with a modern startup-style interface to make career guidance more engaging, interactive, and easy to understand.

---

# 🌟 Features

## 1. Career Prediction Engine

Analyzes user skills and predicts the best career path.

## 2. AI Suggestions

Provides smart recommendations for improving hiring chances.

## 3. Missing Skills Detection

Identifies technologies and skills the student should learn.

## 4. Skill Analysis Graph

Visual representation using Chart.js radar graph.

## 5. PDF Report Export

Allows users to download career analysis reports.

## 6. Dark / Light Mode

Interactive UI theme switching.

## 7. Company Recommendation Engine

Suggests companies based on skill profile.

## 8. Leaderboard System

Displays top-performing student career scores.

# ⚙️ How It Works

1. The user enters personal and academic details such as:

   * Name
   * CGPA
   * Skills
   * Interests
   * Projects

2. The system analyzes the entered information.

3. Based on the provided skills and interests, the application predicts the most suitable career path.

4. The dashboard then displays:

   * Career match percentage
   * Salary prediction
   * Missing skills
   * AI suggestions
   * Recommended companies
   * Skill analysis graph
   * Improvement roadmap

5. Users can also download their career report as a PDF.

The overall goal of the system is to guide students toward better career planning and skill development.
